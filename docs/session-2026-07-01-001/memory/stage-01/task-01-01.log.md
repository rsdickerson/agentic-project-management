# Task 1.1 - Project Scaffolding & HTTP

## Summary

Established the `hello` Python package skeleton with editable-install support and a stdlib-only HTTP fetch layer (`fetch_json`, `fetch_text`) for downstream content modules.

## Details

1. Added `pyproject.toml` with `src` layout, Python 3.10+ requirement, and pytest as an optional dev dependency.
2. Created `src/hello/` package with stub `main()` in `__init__.py` and `__main__.py` entry point for `python -m hello`.
3. Implemented `src/hello/http.py` with `DEFAULT_TIMEOUT = 10`, `USER_AGENT`, and `fetch_json` / `fetch_text` functions accepting optional `user_agent=True` for custom User-Agent headers.
4. Validated editable install and imports in the project venv.

## Output

- `pyproject.toml`
- `src/hello/__init__.py`
- `src/hello/__main__.py`
- `src/hello/http.py`

## Validation

- `pip install -e .` succeeded in `.venv`
- `from hello.http import fetch_json, fetch_text` imports without error
- `DEFAULT_TIMEOUT` is `10`
- Both fetch functions accept `user_agent` keyword argument (verified via `inspect.signature`)
- `python -m hello` exits 0 with stub `main()`
